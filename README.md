# Конструктор Telegram-ботов магазинов (Python)

Платформа-конструктор мультитенантных ботов-магазинов Telegram с поддержкой Mini Apps, автоматической выдачей цифровых товаров, приемом платежей (CryptoBot, xRocket, карты, СБП), системой отзывов и REST API для разработчиков.

## Возможности
- 🤖 **Мастер-бот платформы**: создание и запуск ботов магазинов за пару кликов через Telegram.
- ⚡ **Mini App для каждого магазина**: веб-витрина с каталогом, корзиной, балансом и оформлением заказов.
- 🛍 **Изолированные магазины**: каждый бот запускается независимо, со своими товарами, категориями, настройками и базой клиентов.
- 🔑 **REST API для разработчиков**: создание и удаление магазинов по API с Bearer/X-API-Key токенами.
- 💳 **Платежные методы**: СБП, банковские карты, CryptoBot (USDT), xRocket (USDT).
- 🐍 **Полностью на Python**: Flask + pyTelegramBotAPI (TeleBot) + SQLite3 (WAL).

## Запуск
```bash
pip install -r requirements.txt
python main.py
```
