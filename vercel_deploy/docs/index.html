FACTORY REST API v1

API создания и запуска ботов

Программное создание магазинов, автоматический запуск Telegram-ботов и управление через REST API.

🔑 Авторизация

Передавайте ваш Developer API ключ в заголовке запросов:

Authorization: Bearer sk_live_...
или
X-API-Key: sk_live_...

POST /api/v1/stores

Создать и мгновенно запустить нового бота-магазина с Mini App:

curl -X POST BASE_URL/api/v1/stores \
  -H "Authorization: Bearer sk_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "botToken": "8879846994:AA...",
    "adminId": 8282599467,
    "storeName": "Мой Новый Магазин"
  }'

GET /api/v1/stores

Получить список всех ваших созданных ботов и ссылки на их Mini App:

curl -H "Authorization: Bearer sk_live_..." BASE_URL/api/v1/stores

DELETE /api/v1/stores/{storeId}

Остановить и удалить бота-магазина:

curl -X DELETE BASE_URL/api/v1/stores/shop_a1b2 \
  -H "Authorization: Bearer sk_live_..."
